# Video Agents: правила для агентов

Три роли снимают рекламный ролик: режиссёр, оператор, монтажёр. Каждая роль —
навык в `.claude/skills/<роль>/SKILL.md`. Это единственный источник: Codex
находит их через симлинк `.agents/skills`, копий нет. Читай только навык
нужной роли и справочники из его ссылок.

| Роль | Навык | Вход | Результат |
|---|---|---|---|
| Режиссёр | `director` | пожелание заказчика | задание `briefs/<slug>.json` и `.txt` с промптом |
| Оператор | `operator` | `briefs/<slug>.*` | `output/<slug>.mp4` и `.run-log.json` |
| Монтажёр | `editor` | slug'и планов из `output/` | `output/<name>.mp4` и `.cut-log.json` |

Справочники: `references/seedance-2.5.md` (параметры и границы модели),
`references/prompting-video.md` (промптинг). Читай по задаче, не целиком.

## Правила

- Съёмка (`scripts/generate_video.py`) платная: запускай только после явного
  согласия пользователя на этот ролик. Сначала `--dry-run`: он проверяет
  параметры без токена и сети. Для проверки правок кода и документации
  генерацию не запускай.
- Монтаж (`scripts/assemble_video.py`) локальный и бесплатный; `--dry-run`
  проверяет планы без ffmpeg.
- Скрипты сохраняют код выхода: 0 — успех, 1 — отказ, 2 у съёмки — вышло время
  ожидания (съёмка могла остаться запущенной, id в выводе). Читай код выхода и
  последние строки вывода, а не считай тишину успехом. Полный журнал ffmpeg при
  ошибке — `output/<name>.ffmpeg.log`; читай его фрагментом.
- Модель съёмки одна — `bytedance/seedance-2.5`; не заменяй её и не меняй
  параметры «на ходу».
- Фотографию живого лица на вход не подавай: Replicate её отклонит (E005).
- Ключ Replicate живёт только в `.env`; не печатай и не коммить его.
- `briefs/` и `output/` вне репозитория; готовые ролики пользователя не
  коммить без прямой просьбы.
