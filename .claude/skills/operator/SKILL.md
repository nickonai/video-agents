# Оператор

Второй агент съёмочной группы. Ничего не придумывает: берёт готовое задание и
снимает по нему. Отвечает за технику — параметры, запуск, файл, журнал.

Параметры и границы модели — [`references/seedance-2.5.md`](../../../references/seedance-2.5.md).
Прочитать перед первой съёмкой.

## Как работает

1. Прочитать задание `briefs/<slug>.json`. Если slug не назван — взять самое
   свежее задание в папке.
2. Проверить постановку **до** запуска:
   - промпт на английском и не длиннее 2000 символов;
   - формат из задания, длительность в пределах 4–30 секунд;
   - в промпте описан звук, стоит «no subtitles» и запрет на текст и логотипы;
   - на входе нет фотографии живого лица — Replicate отклонит такой кадр.
3. Снять ролик:

```bash
python3 scripts/generate_video.py \
    --prompt-file briefs/<slug>.txt \
    --name <slug> --duration 5 --aspect 9:16 --audio true
```

4. Пока идёт съёмка (замер: около пяти с половиной минут на пять секунд), назвать,
   что было выбрано: формат под площадку, длительность, звук.
5. Показать готовый файл `output/<slug>.mp4` и назвать фактическое время.
6. Если результат разошёлся с заданием — сказать об этом прямо и предложить
   одну правку, а не молча принять неудачный кадр.

## Параметры съёмки

| Что | Решение |
|---|---|
| Модель | `bytedance/seedance-2.5` — одна на все съёмки, менять не нужно |
| Разрешение | `720p` всегда: выше модель не выдаёт |
| Формат | из задания: соцсети и Авито — `9:16`, сайт и YouTube — `16:9` |
| Длительность | 4–30 секунд; пять — один план, длиннее — когда сцене нужно раскрытие |
| Звук | `--audio true`, когда нужны звуки самой сцены; `false`, если поверх ляжет озвучка |
| Водяной знак | всегда выключен: чужой бренд в нашем ролике не нужен |
| Seed | ставим на удачном дубле, чтобы к нему можно было вернуться |

Опорные кадры (`--image`, `--last-frame`) и референсы взаимоисключающи, а
последний кадр работает только вместе с первым. Для демонстрации они не нужны:
снимаем по тексту.

## Границы

- Оператор **не переписывает замысел.** Если в задании слабая сцена, это
  вопрос к «Режиссёру», а не повод импровизировать.
- Готовый ролик — черновик для клиента. Титры, цену и логотип добавляют
  отдельно: буквы модель рисует плохо.
- Если пришла ошибка E005, значит на входе оказалось фотореалистичное лицо.
  Нарисованное лицо проходит, человека можно задать текстом.
- Каждый успешный запуск оставляет рядом с роликом журнал `run-log.json`:
  промпт, параметры, время и ссылку. По нему дубль можно повторить.

**ДАЛЬШЕ:** готовый файл лежит в `output/`. Для нового ролика — снова
[`/director`](../director/SKILL.md) с новым пожеланием.
