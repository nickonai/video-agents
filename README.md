# Съёмочная группа из трёх агентов

Заказчик говорит своими словами, какой ролик он хочет, — и через несколько минут
получает готовое рекламное видео. Работают три агента.

| Агент | Что делает | Роль в старом мире |
|---|---|---|
| **Режиссёр** — [`/director`](.claude/skills/director/SKILL.md) | Слушает пожелание и превращает его в постановочное задание: сцена, камера, свет, звук, формат, стоп-лист | сценарист и режиссёр |
| **Оператор** — [`/operator`](.claude/skills/operator/SKILL.md) | Проверяет параметры, снимает ролик на Seedance 2.5 и отдаёт файл | оператор, съёмочная группа |
| **Монтажёр** — [`/editor`](.claude/skills/editor/SKILL.md) | Выстраивает планы в осмысленный порядок, склеивает с переходами и сводит звук | монтажёр |

Каждый агент отвечает за одно: первый понимает **что снимать**, второй —
**снимает**, третий — **собирает из планов ролик**. Роли не пересекаются:
оператор не переписывает замысел, монтажёр не спасает неудачный кадр.

Модель — [`bytedance/seedance-2.5`](https://replicate.com/bytedance/seedance-2.5) на Replicate.
Её параметры и ограничения: [`references/seedance-2.5.md`](references/seedance-2.5.md).
Техники промптинга видео: [`references/prompting-video.md`](references/prompting-video.md).

## Примеры

В [`examples/`](examples/) лежит готовая работа группы: рекламная серия для
бренда авосек. Исходник — одна фотография товара на белом фоне
([`avoska-source.jpg`](examples/avoska-source.jpg)).

Три плана сняты по тексту, без опорного кадра — студийное фото на белом фоне
потянуло бы модель против замысла. Сумка описана словами: витой шнур
ультрамарина, крупное ромбовидное плетение, ручки-петли.

| План | Что делает | Хронометраж |
|---|---|---|
| [`avoska-light.mp4`](examples/avoska-light.mp4) | Музейный свет сквозь плетение, тени-ромбы на штукатурке. Останавливает пролистывание | 5,04 с |
| [`avoska-capacity.mp4`](examples/avoska-capacity.mp4) | Руки укладывают апельсины, плоская сетка набирает объём. Снимает возражение «ничего не влезет» | 5,04 с |
| [`avoska-life.mp4`](examples/avoska-life.mp4) | Авоська на плече, золотой час, макро на узлы. Оставляет образ | 5,04 с |
| **[`avoska-reel.mp4`](examples/avoska-reel.mp4)** | **Сборка монтажёра: три плана в одном ролике** | **14,38 с** |

Постановочные задания к планам — в [`examples/briefs/`](examples/briefs/),
журналы запусков лежат рядом с каждым видео: в них промпт, параметры и время
съёмки, по ним дубль можно повторить.

### Как собран `avoska-reel`

Монтажёр поставил планы в порядке воронки — **зацепить → доказать → влюбить**:

| Время | План | Зачем здесь |
|---|---|---|
| 0—4,64 | `light` | Первым идёт самый сильный кадр: в ленте зритель решает за первую секунду |
| 4,64—9,30 | `capacity` | Довод: показывает, как вещь работает |
| 9,30—14,38 | `life` | Последним — образ, его зритель уносит с собой |

Переходы — перетекание 0,4 секунды, звук перетекает вместе с кадром. Рядом с
крупным планом стоит общий, два похожих кадра не встали встык.

Перетекание съедает время: три плана по 5 секунд дают не 15 секунд, а 14,38 —
каждая склейка укорачивает ролик на длину перехода.

## Что нужно для запуска

1. **Claude Code** — среда, в которой живут агенты.
2. **Ключ Replicate** — доступ к модели. Получить: [replicate.com/account/api-tokens](https://replicate.com/account/api-tokens).
   Ключ кладётся в файл `.env` рядом с проектом и никуда не отправляется.
3. **ffmpeg** — нужен монтажёру для склейки. На macOS: `brew install ffmpeg`.
4. Всё остальное уже в репозитории.

## Как запускать

```bash
git clone https://github.com/nickonai/video-agents.git
cd video-agents
cp .env.example .env      # и вписать свой ключ Replicate
claude
```

Скиллы подхватываются из `.claude/skills/`, поэтому запускать Claude Code нужно
из папки репозитория. Дальше в диалоге:

```
/director хочу ролик для кофейни в Казани, чтобы было уютное утро и хотелось зайти по дороге на работу
```

Режиссёр показывает задание и кладёт его в `briefs/`. Затем:

```
/operator kofeynya
```

Оператор снимает и кладёт готовый файл в `output/kofeynya.mp4` вместе с
журналом запуска. Когда планов несколько:

```
/editor kofeynya-utro kofeynya-zerno kofeynya-chashka
```

Монтажёр собирает их в один ролик и пишет рядом монтажный лист.

## Границы модели

Фотографию живого лица на вход подавать нельзя — Replicate отклоняет такой
кадр (ошибка E005). Нарисованное лицо проходит, человека можно описать
текстом: в примерах выше люди есть, но кадр обрезан по плечу и по рукам.

Промпт — не длиннее 2000 символов, длительность — от 4 до 30 секунд,
разрешение — 720p. Время съёмки плавает сильно: пять секунд занимали от
2 до 5,5 минут, планировать стоит по верхней границе.

Буквы модель рисует плохо. Название, цену и логотип кладут оверлеем в
монтажной программе поверх готовой сборки — место под них режиссёр
оставляет в кадре заранее.

## Что где лежит

```
.claude/skills/     режиссёр, оператор, монтажёр
scripts/            съёмка (generate_video.py) и сборка (assemble_video.py)
references/         канон: параметры модели и техники промптинга
examples/           готовая работа группы: три плана и сборка
briefs/             задания текущих съёмок (не в репозитории)
output/             отснятое и собранное (не в репозитории)
```
